วิธีติดตั้งมุยมุยมัดแก้ไข
1) แตก ZIP นี้ลงโฟลเดอร์
2) เปิด CMD ในโฟลเดอร์ แล้วรัน: py -m http.server 8000
3) เปิด Chrome: http://localhost:8000/muimui_pwa_notification_starter.html
4) กดเมนู Chrome ⋮ แล้วเลือก Install page as app (หรือปุ่มติดตั้งในเว็บ)
หมายเหตุ: localhost ใช้ทดสอบบนเครื่องเดียว; ใช้มือถือหรือ Push จริงต้องโฮสต์ HTTPS และตั้ง backend เพิ่ม
